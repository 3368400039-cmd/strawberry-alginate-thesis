## 1. 结论与判定限度

**停止仅按17933个叙述汉字要求补2067字的单一判定。**模板确有“从第1章至参考文献”篇幅范围，本轮对应C；未确认20000的学校数字门槛、具体计数算法或必须使用哪款软件。实际兼容引擎对C报告23697，程序按可见文本统计C为20012个基本汉字；去除续表重复标题/表头的控制范围C0为19961个基本汉字。上述结果均公开保留，不择有利数字宣布学校达标。

## 5. 可复核提取位置与统计步骤

交付DOCX保留以下零宽书签，正文中不显示、不计字：`PF_ABSTRACT_ZH`、`PF_ABSTRACT_EN`、`PF_TOC`、`PF_CHAPTER1`—`PF_CHAPTER4`、`PF_CONCLUSION`、`PF_REFERENCES`、`PF_APPENDIX`、`PF_ACK`。对应范围是：A在CHAPTER1至REFERENCES前筛选Normal叙述段（排除图/公式段），B为CHAPTER1至REFERENCES前全部，C为CHAPTER1至APPENDIX前全部，D为ABSTRACT_ZH至ACK前全部，E为CHAPTER1至CONCLUSION前全部。标题/表/公式/图注的样式均实际保留，图题用PF Caption、图注PF Note；数学内容以`m:t`读取，表格按单元格自然顺序、分隔符另起行，不能直接粘接数字。

程序分类规则如下（这段是核验代码，不是论文内容）：

```python
import re, unicodedata
def counts(visible_text):
    normalized = unicodedata.normalize("NFKC", visible_text)
    han = len(re.findall(r"[\u4e00-\u9fff]", visible_text))
    english = len(re.findall(r"[A-Za-z]+(?:[-'][A-Za-z]+)*", normalized))
    numbers = len(re.findall(r"\d+(?:[.,]\d+)*(?:[eE][+-]?\d+)?", normalized))
    return han, english, numbers, han + english + numbers
```

英文及变量如SA-Ca为一个字母词元；Day0、CaCl₂中的字母与数字分别统计（下标数字先NFKC）；连续小数/带逗号数字按给定正则取组，不解释成统计样本量。行内公式的变量/数字可被程序提取，独立公式仅在B—E相应范围。A历史汉字数不含数字或英文。

复核流程：①在工作副本按上述书签边界导出范围DOCX，保留被选内容的实际表/公式，清除其他正文和页眉页脚；②输出对应可见文本并按上述函数分类；③执行`soffice --headless --convert-to odt --outdir 临时目录 范围.docx`；④以ZIP打开ODT/meta.xml，取命名空间`urn:oasis:names:tc:opendocument:xmlns:meta:1.0`的document-statistic word-count；⑤C0另移除“续表3-1…”段及第二段表的重复表头，仅作控制。软件保存时可能不同步完整页布局，页数另以PDF实渲染为准。

实际中间统计记录保存在本次临时目录，正式报告已登记结果、版本、DOCX SHA和算法。临时PDF/ODT/截图不新增到受控仓库，避免超出五项交付；第三方可据交付DOCX在相同工具重建。跨软件数值差异应另记，不能改正文以迎合当前数字。
