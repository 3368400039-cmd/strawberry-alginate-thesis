## 复现与检查

在仓库根目录、有Python 3.12、python-docx、PyMuPDF、lxml及Pandoc 3.1.11.1的环境中：

```bash
python deliverables/phase09j/scripts/verify_artifacts.py
```

该检查只读对照已核准48个统计组合、正文与附表、六张图片、20个引文身份、目录和受保护路径，不重新读取或计算实验工作表。加`--record`仅更新本目录的自动复核记录。

```bash
python deliverables/phase09j/scripts/build_docx.py
```

该命令从本轮章节、摘要元数据、原学校模板和只读批准图表重新装配本目录Word，会覆盖本目录的`最终初稿.docx`；不会改变任何实验输入。已在临时输出文件上实际复现，所有DOCX包内文件内容一致。修改正文后须重新渲染并同步目录缓存，不能把当前页码缓存直接用于不同内容。

PDF使用LibreOfficeDev 26.8.0.0.alpha0实际转换，并保留空白背面页；字体替代配置见[scripts/fonts_preview.conf](scripts/fonts_preview.conf)。这是一份预览配置，不是学校真实字库。当前45页图版和放大页在`audit/版面证据/`，旧09I的44页只读回看记录列于排版报告。
